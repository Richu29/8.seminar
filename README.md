2. Miks on inline style halb tava?
Stiile peab kordama igal elemendil, mistõttu on muutmine tülikas.
HTML ja CSS lähevad segi, mis teeb koodi raskemini loetavaks.
Inline-stiil kirjutab üle teised reeglid, mistõttu on seda raske hiljem muuta.
